# App Partido Directo

## Objetivo
Crear una aplicación para seguir partidos de fútbol en directo.

## Funciones principales
- Marcador en tiempo real.
- Cronómetro del partido.
- Goles.
- Tarjetas.
- Cambios.
- Alineaciones.
- Estadísticas.
- Notificaciones.

## Tecnologías
- Firebase
- GitHub
- react
- JavaScript
- HTML
- CSS
